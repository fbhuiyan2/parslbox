# ParslBox Manuscript Materials

This directory contains supporting materials for the ParslBox manuscript. The repository-facing materials are:

- `si_session_haiku.md`: curated Haiku 4.5 session showing input preparation, ParslBox DAG registration, scheduler-command correction, and scheduler acceptance for the LiCl-NaCl training-data workflow.
- `prompt_licl-kcl.md`: sanitized prompt used to initiate the corresponding LiCl-KCl training-data workflow. Credentials, allocation identifiers, usernames, and site-specific paths are replaced with placeholders.
- Manuscript PDF: the submitted manuscript containing the main text, figures, results, and discussion. It will be added to this directory after the SC26 conference.

The curated session ends at scheduler acceptance. Production MD simulations used to calculate radial distribution functions were added in a follow-up session and are not included in the session transcript.
